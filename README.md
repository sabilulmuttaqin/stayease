# StayEase

StayEase adalah aplikasi berbasis web yang dirancang untuk mempermudah proses penyewaan kos-kosan, apartemen, dan kontrakan. Aplikasi ini dibangun menggunakan framework **Laravel**, admin panel dengan **Laravel Filament**, dan **Blade** sebagai template engine untuk antarmuka pengguna. StayEase menawarkan solusi lengkap untuk pengelolaan properti sewa secara efisien dan modern.

---

## Fitur Utama

### Untuk Penyewa:
- **Pencarian Properti**
  - Cari kos-kosan, apartemen, atau kontrakan berdasarkan lokasi, harga, dan fasilitas.
- **Detail Properti**
  - Informasi lengkap termasuk foto, deskripsi, fasilitas, dan harga sewa.
- **Pemesanan Online**
  - Pemesanan langsung dengan konfirmasi instan.

### Untuk Pemilik Properti:
- **Manajemen Properti**
  - Tambahkan, edit, dan hapus properti yang disewakan.
- **Statistik Pemesanan**
  - Laporan tentang jumlah penyewa, pendapatan, dan status pembayaran.

### Admin Panel (Laravel Filament):
- **Manajemen Pengguna**
  - Kelola data penyewa dan pemilik properti.
- **Manajemen Transaksi**
  - Pantau dan kelola semua transaksi penyewaan.
- **Notifikasi dan Log Aktivitas**
  - Sistem notifikasi untuk memastikan semua aktivitas tercatat.

---

## Teknologi yang Digunakan

- **Laravel**: Framework backend untuk pengelolaan database, logika bisnis, dan API.
- **Laravel Filament**: Untuk admin panel yang cepat, responsif, dan mudah dikustomisasi.
- **Blade Template Engine**: Untuk membangun antarmuka pengguna yang dinamis dan ramah pengguna.
- **Database**: MySQL untuk penyimpanan data.
- **CSS Framework**: TailwindCSS untuk desain yang modern dan responsif.

---

## Panduan Penggunaan

### Penyewa
1. Registrasi akun.
2. Login untuk mengakses properti.
3. Cari properti yang sesuai dan lakukan pemesanan.

### Pemilik Properti
1. Registrasi akun.
2. Tambahkan properti dengan detail lengkap.
3. Pantau statistik penyewaan melalui dashboard.

### Admin
1. Login ke admin panel melalui Filament.
2. Kelola data pengguna, properti, dan transaksi.
